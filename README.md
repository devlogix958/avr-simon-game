AVR Simon Game

A simple Simon style memory game written in C for the ATmega328P. 
The game generates a random LED sequence that the player has to reproduce using buttons.

Build:

make

Flash:

make flash

Clean:

make clean

Hardware:

The project uses an ATmega328P, three LEDs, and three buttons
